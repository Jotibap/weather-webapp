# weather-webapp

This project is a simple weather web application built using HTML, CSS, and JavaScript. It allows users to check the current weather conditions for a specified location.

Features
Current Weather Display: Shows the current weather conditions (temperature, humidity, wind speed, etc.).

Location Search: Allows users to input a location to get weather data.

Responsive Design: Ensures usability across different devices (desktops, tablets, and mobile phones).

Technologies Used
HTML

CSS 

JavaScript
